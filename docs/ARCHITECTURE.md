# Prototype architecture

- **React 19 + Vite:** fast local product loop.
- **Astryx:** selected accessible controls and design-system foundation.
- **Custom document surface:** typography and reading interactions need a distinct editorial layer.
- **Storybook:** isolated component review.
- **Tauri 2:** cross-platform desktop wrapper.
- **Browser SpeechSynthesis:** zero-backend text-to-speech demonstration.
- **Static document model:** deterministic prototype data before introducing AI variability.

Future seams: document adapters, local SQLite, annotation anchors, AI provider abstraction, embeddings, and sync.
