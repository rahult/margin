The reading loop

Built for comprehension, not consumption.

Reading map

Any Markdown file becomes a guided argument

Sections with priming questions, reading-time estimates, and progress that survives restarts. Arrow keys move you forward; the goal-gradient copy tells you how close you are.

Thinking companion

Ask, don't skim

Grounded answers about the section you're on, from any OpenAI-compatible model. Your key stays in a local proxy — it never ships to the frontend.

Argument maps

Firm up the idea

For ADR/RFC-shaped docs the companion extracts decision, reasons, rejected alternatives, and trade-offs — editable, persisted, yours.

Knowledge that connects

Notes that find each other

Margin notes are atomic cards anchored to their section. The companion suggests links to notes in your other documents; you confirm, and the dots connect across everything you've read.

Local TTS

Listen, really

Human-quality neural voice (Kokoro-82M) narrating section by section — fully on-device after a one-time model download.

Coins

A game about finishing documents

Sections, notes, review answers, and listening earn gold coins. A hundred in a month waives the renewal. Retrieval practice at the end of each doc is where the real payout — and the real learning — happens.

Agent bridge

Your coding agent reads what you distilled.

Margin ships an MCP server. Claude Code, Cursor, Codex — any MCP client — can pull a spec and review it with your notes, review answers, and argument map attached as context.

Read in Margin

Notes, argument maps, and review answers are written to a local store as you work.
